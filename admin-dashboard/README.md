# AIDRA Command Center

Responsive React/Vite operations dashboard. Local `.env.local` points `VITE_API_URL` at `http://localhost:3000/v1`. Run `npm install`, place an authorized Firebase ID token in `localStorage` as `aidra_token`, and run `npm run dev`. Without a backend response, the dashboard displays demo sample data. Admin API data requires authority/NGO/superAdmin role.
